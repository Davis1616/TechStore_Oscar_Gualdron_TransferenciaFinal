TechStore:

Aplicación móvil desarrollada en Android Studio orientada al comercio electrónico de productos tecnológicos.

Descripción

TechStore es una aplicación Android que permite la gestión y comercialización de productos tecnológicos mediante un sistema moderno de m-commerce. El proyecto integra autenticación de usuarios, gestión de roles, catálogo de productos, carrito de compras y servicios de Firebase.

Funcionalidades principales:
- Registro e inicio de sesión
- Gestión de usuarios por roles
- Catálogo de productos
- Carrito de compras
- Geolocalización
- Recuperación de contraseña
- Integración con Firebase Authentication
- Base de datos Firestore

 Tecnologías utilizadas:
- Java
- XML
- Android Studio
- Firebase Authentication
- Firebase Firestore
- APIs de ubicación

 Estructura del proyecto:

app/
 ├── java/com.example.techstore
 │    ├── activities
 │    ├── adapters
 │    ├── models
 │    └── firebase
 │
 ├── res/
 │    ├── layout
 │    ├── drawable
 │    ├── values
 │    └── mipmap
```

## Estado del proyecto

Proyecto en desarrollo académico orientado a la implementación de comercio electrónico móvil seguro y escalable.
